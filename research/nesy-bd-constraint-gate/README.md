## Overview

This directory anchors the camera-ready research assets for **Paper 1**:
* **Title:** *NeuroSym-BD: Neuro-Symbolic AI for Violence Event Extraction, Ontological Constraint Validation, and Escalation Modeling from Bangladeshi News*
* **Core Contribution:** Decoupled Description Logic ($\mathcal{SROIQ}$) state-transition constraint gates (C-ONTO) over dense neural sequence representations in BlazeGraph, cutting false positive rates to 1.0% ($96.8\%$ precision, $85.3\%$ accuracy) with 98% source sentence provenance.

All source code, data, and reproduction scripts remain intact in their canonical root locations (`paper/`, `submission/`, `evaluation/`, `ontology/`).
