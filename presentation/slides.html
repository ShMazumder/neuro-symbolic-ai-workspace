The Research Gap

The Single-Paradigm Failure in Conflict Analysis

⚠️ Pure Neural Approach (LLMs / BERT / GNN)

  • Hallucinations & False Jumps: Predicts extreme mass violence from minor verbal threats without checking escalation rules.
  • Zero Logical Enforceability: No formal constraint verification (e.g. geographic or temporal consistency).
  • Black Box Auditing: Cannot provide strict W3C provenance citations linking back to original news sentences.
  • High Inference Cost: Unfeasible for continuous 24/7 live news streams.

⚠️ Pure Symbolic Approach (CAMEO / GDELT / Rules)

  • Semantic Fragility: Breaks on lexical variations, sarcasm, and complex syntax in news writing.
  • Western Ontology Bias: Standard CAMEO (13-20) lacks Bangladesh local conflict modes (hartals, mob beatings, crossfire).
  • Static Knowledge: Fails to discover latent, emergent topological patterns across multi-hop entity graphs.
The Solution: NeuroSym-BD
Combines data-driven neural extraction & forecasting with rigid OWL ontology constraints and a W3C PROV-O knowledge graph.

Information Extraction

Multi-Stage NLP Extraction Architecture

1. Relevance Filter

Two-tier screening:

  • Fast Keyword Regex: 50+ BD violence keywords (crossfire, dowry, gunfight).
  • Zero-Shot Classifier: Dispatches uncertain articles to BART-Large-MNLI.
  • Filters out economic and sports articles instantly.

2. Event Triggers & NER

Predicate & entity mapping:

  • Trigger Verbs & Nouns: Lemmatized lexicons mapping verbs (kill → 182, clash → 145).
  • spaCy NER + Regex: Extracts PER, ORG, GPE with local political alias resolution.
  • Argument Roles: Differentiates Perpetrator vs Victim.

3. Geo & Temporal

Standardized normalization:

  • 64 BD Districts: Mapped to coordinates and 8 administrative divisions.
  • ISO 8601 Dates: Resolves relative timestamps ("yesterday afternoon", "Friday night").
  • Generates structured EventRecord.

The Core Innovation

Constrained Hybrid Inference Engine

Neural Subsystem

Statistical representation:

  • R-GCN (Relational GCN): Learns multi-relational structural embeddings over the event graph.
  • BiLSTM Forecaster: Models sequential escalation probabilities over time.
  • Outputs raw logits: $\hat{y}_{neural}$.

Symbolic Subsystem

Formal rule validation:

  • Ontological Constraints: Restricts illegal CAMEO transitions (e.g. $13 \not\to 20$).
  • Spatial Constraints: Verifies district-division hierarchy ($d \in Div$).
  • Actor Compatibility: Validates perpetrator capabilities.

Hybrid Decision

Calibrated output:

  • Hard Violations: Rejects invalid jump → falls back to safest ancestor code.
  • Soft Violations: Applies calibrated confidence penalty.
  • Generates full audit report with explanations.
Predictive Analytics

Escalation Forecasting & Anomaly Spike Alerts

Temporal Sequence Escalation (BiLSTM)

  • Models historical trajectories: Threat → Protest → Clash → Assault.
  • Predicts transition probability $P(Code_{t+1} \mid Code_{1:t})$ across districts.
  • Pre-event early warning alerts generated 24–48 hours before predicted escalation.

Statistical Anomaly Detection

  • Poisson Baseline: Flags event counts exceeding $\mu + 2.5\sigma$ in any district.
  • CUSUM (Cumulative Sum): Detects subtle drift towards systemic instability.
  • Severity Index: Integrates fatality count and weapon intensity metrics.

Practical Applications

Graph-RAG & NL2SPARQL Interrogation

1. Graph-RAG Q&A Engine

Combines graph retrieval with LLM synthesis:

  • User asks: "Where did election-related clashes occur in Khulna last week?"
  • Engine executes SPARQL query on BlazeGraph to retrieve gold entity subgraphs.
  • LLM formats concise answer with 100% verified citations from knowledge triples.

2. NL2SPARQL Translation API

Enables non-technical analysts to query the graph:

  • Translates English queries into standard SPARQL 1.1 syntax.
  • Enforces schema constraints against cameo_base.ttl and cameo_bd_extension.ttl.
  • REST API endpoints ready via FastAPI on ports 8001 & 8002.
Limitations & Future Work

Honest Appraisal & Future Directions

Acknowledged Limitations

  • Single-Source Recall Bound (17.3% vs ACLED): Evaluated against a single English newspaper (*The Daily Star*) vs ACLED's multi-source nationwide field reporting.
  • Language Barrier: Bengali-language regional portals (Prothom Alo, Ittefaq) contain more rural violent incidents not covered in English dailies.

Immediate Next Steps

  • Multi-Outlet Bengali Scraping: Expand crawler to Bangla news portals using multilingual spaCy and BanglaBERT.
  • Online Neuro-Symbolic Continual Learning: Incrementally update GNN embeddings as live news streams in.
  • Policy Dashboard Deployment: Interactive Streamlit map for disaster/conflict prevention NGOs.
